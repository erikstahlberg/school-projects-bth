###Vad tycker du om LESS så här långt, och det sättet vi jobbar med LESS-moduler i vårt tema?
Det är helt klart värt att investera tid eftersom det spara så mycket tid i slutändan.
Ett väldigt bra exempel på detta är att kunna använda variabler i multipla klasser.
Det gör att man enbart behöver ändra på ett ställe. Jag irriterade mig på det när
vi enbart satt i CSS men nu blev det helt plötsligt mycket bättre. Att använda
moduler gör koden betydligt mer hanterbar. Det känns som det är i stort sett
samma som ren CSS men med de tillägg som verkligen behövs för att snabba upp arbetet.

###Hur kändes det att kompilera LESS till CSS, var det något du reflekterade över?
Att kompilera med LESS var väldigt enkelt när man kunde använda Makefiler. Visst det
blir ett moment till som måste göras för att få fram den användbara CSS-filen.
Dock som jag sa innan sparar det betydligt mer tid i andra delar.

###Har du varit bekant med Makefiler och make sedan tidigare, eller något liknande byggverktyg? Hur uppfattar du make så här långt?
Jag har aldrig använt Makefiler och visste inte ens att det existerade sen innan
denna kursen. Jag kan inte heller komma på något liknande byggverktyg mer än kanske
skrivna plugin till Autodesk Maya som agera som samma princip med att exekvera
olika kommandon som snabba upp arbetet. Jag funderar dock på att också titta över
för att skriva kortare kommandon till git, bara för att snabba upp saker.

###Fann du nytta i de videor som var kopplade till detta kursmoment?
Jag har tittat igenom videorna för både anax-flat och LESS. De var båda väldigt informativa
och lätta att förstå. Bra förklaring till LESS där man får en bra grund till att
använda preprocessorn. Även texterna var både intressant och förklara vad man
bör undvika för fallgropar att falla i. Småsaker som verkligen gör skillnad på en
webbplats. Skapa tydlig länkar som sticker ut i övrig text, överväg eventuellt
kvarhängande menyer för långa sidor osv. Jag har precis fått tag på boken "Beautiful
Web Design" så har inte hunnit läsa särskilt mycket i den än. Jag vet att den finns på
BTH online-bibliotek men föredra böcker betydligt mer. Den verka bra och beskriver
bra saker som till exempel att hålla ett sammanhängande tema över multipla sidor
på en webbplats.
